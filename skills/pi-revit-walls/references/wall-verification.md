# Wall inspection and verification

Read this for wall audits, quantity questions, or to check a proposed or completed wall change. The shared PI-Revit execution rules still govern model identity, transactions and recovery.

## Establish the requested evidence

For a question about the current model, identify the intended document and phase/view, then discover wall IDs and types rather than relying on displayed names. Inspect `WallType.Kind`, instance type ID, base/top constraints, path, `Flipped`, local exterior side, `CrossSection`, room bounding, structural usage, joins, attachments, hosted inserts, and any curtain/stacked members relevant to the task. Decide whether the user needs a count, a property audit, measured geometry, a drawing, or a material takeoff; these need different evidence. [Wall class](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/b5891733-c602-12df-beab-da414b58d608.htm).

`get_elements` and `get_element_details` provide bounded listings and parameter details; `get_element_types` discovers type IDs; `get_element_relationships` helps with host/member relationships; `measure_geometry` and `query_spatial_elements` are approximate spatial aids. Read each selected tool manual and live schema. Use `search_api_docs` then read-only `execute_csharp` for geometry or relationships not exposed by a dedicated tool. A bounding box can establish an envelope but cannot prove the exact exterior face, core face, curvature, opening or join. [PI-Revit tool index](../../pi-revit/references/tool-index.md).

## Check the physical result

After a requested wall write, separate committed `succeeded` rows from rolled-back `proposed` IDs and failed rows. The current tool returns `actual` after commit, or `actual_read_error` if its post-commit reread failed; a readback error does not undo the commit. Independently reread retained IDs. Verify `actual.wall_kind`, `location_curve_type`, `profile_sketch_id` where relevant, the selected type and compound structure, path and plane alignment, physical base/top, cross section and angles, joins, inserts, room boundary and structural designation as required. `actual` lengths and positions are internal feet and angle parameters are radians, regardless of the request's `unit`. Check `model_changes` for affected neighbors and warnings for Revit-rejected or adjusted geometry. [Current PI-Revit wall manual](../../pi-revit/references/tools/create_walls.md).

For location-line alignment, compare the requested physical plane with the actual wall face or compound-structure offset; Revit's `LocationCurve` can remain at the wall center. For curved walls, use local tangents/normals or geometry references along the curve. For slanted/tapered walls, inspect section/3D geometry at relevant heights. For a profile, check the closed boundary and openings in elevation. For curtain walls, inspect grids, panels and mullions separately; for stacked walls, inspect subwalls. A plan image alone cannot verify elevation constraints. [Wall API guide](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API/files/Revit_API_Developers_Guide/Revit_Geometric_Elements/Walls_Floors_Ceilings_Roofs_and_Openings/Revit_API_Revit_API_Developers_Guide_Revit_Geometric_Elements_Walls_Floors_Ceilings_Roofs_and_Openings_Walls_html.html), [CurtainGrid API](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/5e0d5b7c-aaa1-d299-6fb8-2faa65b1857a.htm).

Where a visual result is requested, capture a relevant plan plus elevation/section or 3D view as needed, inspect the actual image, then stop once the requested result is verified. A capture or exported image is evidence, not an RVT save. [PI-Revit visual verification](../../pi-revit/references/visual-verification.md).

## Dimensions and quantities

Use the current wall's path length, height/constraints, width, calculated area and volume according to the user's quantity definition. An opening, hosted insert, sweep/reveal or join can change net geometry; multiplying length × height × width is only a rough geometric estimate. Revit's material API provides `Element.GetMaterialIds`, `GetMaterialArea` and `GetMaterialVolume` for supported elements. Material area can distinguish paint from non-paint. Curtain-wall material takeoff belongs to panels/mullions rather than the overall curtain wall. Revit warns that layer quantities can differ slightly from visible geometry under sweeps, reveals and some joins. Report whether a result is an API quantity, a schedule value, or an independent geometric estimate. [Autodesk material quantities](https://help.autodesk.com/cloudhelp/2024/ENU/Revit-API/files/Revit_API_Developers_Guide/Revit_Geometric_Elements/Material/Revit_API_Revit_API_Developers_Guide_Revit_Geometric_Elements_Material_Material_quantities_html.html), [GetMaterialArea](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/02417c40-bcc4-f04c-9897-cf47737e8739.htm).

For drawing dimensions, obtain stable geometric references in the intended view; `NewDimension(View, Line, ReferenceArray, DimensionType)` needs valid geometry references. A measured numeric distance is not automatically a persistent Revit dimension. Inspect the created dimension's references and visible placement in the view. [NewDimension API](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/475aab91-19d3-5884-d3eb-18dfc0d4004f.htm).

Raw Revit lengths, areas and volumes use internal units. Convert with the current API's unit spec/ForgeTypeId or the relevant PI-Revit tool's explicit unit contract; do not infer units from localized `displayValue`. Keep model-derived measurements separate from requested design values and from country-specific compliance claims. [PI-Revit execution rules](../../pi-revit/references/execution-rules.md).
